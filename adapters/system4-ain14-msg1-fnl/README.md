# System4 AIN v14 MSG1 + FNL

独立 C# 适配器源码，使用主程序的 JSON IPC 协议。按资源格式和运行程序内容识别，不依赖游戏名称。

- 读取 AI2 压缩的 AIN v14 消息表，保留非消息数据，支持变长回填。STR0、EX、程序菜单和图片文字不在提取范围内。
- 原字体字形保持不变；缺少的 BMP 字符使用 Windows 宋体（SimSun）补字，最多共享 1880 个 CP932 私用码位。创建字体后核实实际选中的字体，拒绝无字形替代。
- 输出独立的 `.zh.exe`，原 EXE 原样保留。配套 AIN、FNL 与新启动程序需要一起安装。
- 运行程序修补按完整代码节 SHA256 和 PE 布局匹配。同一运行时仅图标、版本资源等变化时可复用；`RuntimePatch.cs` 根据代码节位置定位修改，修复文字遍历及 FNL 字形索引对 F0–F9 的限制。不同代码版本需要单独分析和验证，不能直接套用偏移。
- 字节回填、字形存在性和 PE 检查不代表游戏内渲染已验证。请使用少量试译确认字体、排版和实际运行效果。

已有试译项目可在关闭汉化工具和游戏后运行：

```powershell
.\scripts\repair-system4-font.ps1 -ProjectDirectory '<数据目录>\games\<项目 ID>' -Install
```

脚本编译并验证适配器，复用选区中的缓存译文生成补丁，然后更新项目使用的版本。`-Install` 使用主程序的补丁安装器安装；省略时仅生成补丁。不会请求翻译 API。
