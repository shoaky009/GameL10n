# 使用、备份与续译

## 导入与翻译

选择包含游戏程序和资源的安装目录。识别完成后，界面显示文本数量、适配能力和已知限制。译文范围包括对白、旁白、角色名和选项，不包含图片内文字。

“API 与术语”的“翻译语言与术语”中，术语表每行填写 `原文=译文`。更改术语后，只会使受相关术语影响的译文缓存失效。分析和翻译分别选择 API 配置，见[模型接口配置](model-providers.md)。

## 少量试译

识别游戏后点击“选择文本试译”，按脚本筛选或搜索游戏画面里的原文，逐条勾选要验证的角色名、对白、旁白和选项；也可批量加选当前列表的前 N 条。切换脚本和搜索不会清空选择，勾选“仅显示已选文本”可以复查。列表顺序是资源提取顺序，不代表剧情播放顺序，建议选择开场或可以从存档到达的片段。

点击“试译并生成补丁”后，只翻译选中的文本，其余文本保留原文，即使它们已有缓存译文也不会加入本次试译补丁。在“汉化补丁”点击“安装试译补丁”，按界面提示的启动方式进入游戏，对照字体、乱码、换行、角色名和选项显示。补丁目录中的 `trial-texts.json` 保存本次所选原文、译文、脚本和位置。结构校验通过不代表已经验证游戏显示。

试译中断后，重新打开“选择文本试译”会恢复上次选区；再次生成时复用已完成译文。验证满意后点击“开始 / 继续全量翻译”，试译译文会继续复用，不需要重新付费翻译。试译和全量补丁分开保存，安装仍使用原有 `.bak` 备份与恢复机制。

SFA16 / AOS v2 的中文启动程序统一使用 CP936。保留的日文会以该编码写入；不支持的符号“・”和“♪”分别显示为“·”和“～”，受影响条数会记录在补丁警告中。原文快照保持不变。

## 安装与恢复

“汉化补丁”显示产物目录、启动方式和验证状态。安装器只写入补丁清单声明的文件，替换前备份原文件为 `.bak`；已有同名备份时，使用带时间和唯一标识的 `.bak` 文件名，保留旧备份。目标文件版本与制作补丁时不符时停止安装。

点击“安装试译补丁”或“安装汉化补丁”会自动写入导入时选择的游戏目录，无需手动复制。只读原文件在备份和校验完成后解除只读限制以便替换，恢复原版时恢复其只读属性。安装结果或失败原因直接显示在补丁页；安装前请关闭游戏。

“恢复原版”恢复原文件并移除本工具新增的补丁文件。安装后被游戏更新或其他程序修改的文件不会被强行覆盖，冲突会显示在日志中。

结构校验通过说明资源符合适配器的结构要求。游戏显示、排版、分支和存档兼容性需要实际运行验证，界面单独显示此状态。

## 缓存与续译

已完成译文按原文、上下文、文本类型、目标语言、风格和相关术语匹配。近似原文不直接复用。暂停或重新打开程序后，再次识别同一游戏并开始翻译即可继续；已安装补丁的游戏从经过校验的原文件备份读取原文。

每批模型响应先保存，再提交译文缓存。翻译 API 请求失败后，每隔 10 秒重试一次，最多重试 5 次（加上首次请求共 6 次）；全部失败后任务暂停。继续全量翻译或重新提交相同试译选区会复用已保存的译文，只处理未完成的文本。等待重试期间也可以手动暂停。

数据默认保存在 `%LOCALAPPDATA%\AvgTranslator`，包括任务、原文快照、译文、补丁、扩展和兼容记录。可通过环境变量 `AVG_TRANSLATOR_DATA` 指定其他位置。原文快照和模型响应可能包含游戏文本。

## 汉化产物与适配器

安装后的游戏使用汉化资源和必要的中文启动程序，不需要本工具、适配器或模型服务。引擎／模板适配能力保留在制作工具中，用于制作其他游戏的补丁或处理资源更新。临时开发目录不属于玩家需要的汉化产物。
