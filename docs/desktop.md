# 桌面交互与状态

桌面界面使用 Slint，跟随系统深浅主题，时间按系统时区显示。

## 项目列表与按需加载

添加项目时选择具体游戏的安装目录。目录疑似包含多个游戏时会提示确认；磁盘或共享根目录不能作为项目。

选择目录和添加项目期间，“添加游戏”按钮暂时禁用，重复触发不会打开多个选择窗口。取消或添加结束后可再次使用。

重新添加同一游戏目录时，已有文本和校对数据直接保留；项目数据已删除而全局库仍保留该游戏的适配器时，自动执行本地探测、校验和文本提取。没有可用历史记录时等待手动识别；本地找回失败时保留原因，添加操作不调用分析 API。

运行或排队的项目置顶，其余按最近更新时间排序，支持名称搜索。浏览项目和任务进度不改变排序时间。

打开项目只读取设置和已有结果，不自动识别。进入“翻译与校对”后才加载文本和保存的勾选，文本分页显示并复用缓存。尚未提取时显示等待提示，已有提取文件损坏时报告错误。

项目未单独配置的选项使用全局默认，修改后仅该项采用项目值，详见[模型接口配置](model-providers.md#按用途选择)。

## 文本选区与校对

- “选中本页”添加当前页；“全选匹配”添加当前筛选结果；“清空”移除全部勾选。选区跨页和筛选保留，可切换为仅显示已选文本。
- 原文、译文和上下文支持文字选择与复制。“复制原文／译文”复制完整内容，校对区复制当前编辑内容。
- 切换文本、翻页、筛选或生成补丁前保存编辑。后台刷新保留未保存草稿，其他项目的结果不会覆盖当前编辑器。
- 普通翻译复用有效译文；重新翻译只处理所选文本。失败记录与旧有效译文独立，可通过“翻译失败”筛选重试。

## 任务、结果与日志

“识别游戏”先执行常规适配，必要时进入智能适配；状态分别显示当前路径。修复问题或补全遗漏文字直接进入对应智能任务，流程见[识别与智能适配](adapters/automatic-adaptation.md)。

运行中的任务直接展示当前步骤、关键进展、所用 API 和 Token 用量。已完成项目显示识别结果、支持范围和待验证项。Token 使用 K / M 简写，悬浮可查看精确值。

日志固定在底部自动跟随，向上滚动后暂停，可点击“回到最新”恢复。日志和错误信息支持选中复制。处理文件时显示操作、文件名和大小；模型进展与日志规则见[执行与恢复机制](adapters/adaptation-internals.md#进展结果与用户日志)。

## 消耗指标

左侧“消耗指标”支持按日期、版本、模型配置、游戏和任务类型组合筛选。模型配置按“配置名称 / 模型 ID / 推理强度”区分，Token 用量用三种颜色的折线展示输入、输出和缓存输入，其他指标使用柱条，并可切换到执行记录。统计口径及轻量存储见[消耗指标](consumption-metrics.md)。

## 补丁文件

“补丁与验证 → 打开补丁文件”打开补丁的 `files/`，其中的目录结构与游戏一致，可直接复制全部内容到游戏目录并覆盖。清单、报告和验证记录保留在该目录之外，详见[补丁产物](adapters/artifacts.md#汉化运行文件与补丁记录)。

## 导航与引擎库跳转

左侧底部的“关于”显示项目简介、软件版本号、构建时的 Git 提交哈希、GitHub 仓库地址和主程序许可证。版本、哈希和仓库地址支持选中复制；仓库、发布更新、问题反馈、使用文档、更新日志、许可证及第三方声明可在默认浏览器打开。版本、仓库和许可标识取自应用的 Cargo 元数据；没有可读取 Git 信息的构建显示哈希为“未知”。安装后的程序不需要 Git 即可查看这些信息，访问在线链接需要网络连接。

项目中的引擎和适配器版本、引擎库中的兼容游戏与经验来源均可通过名称链接跳转。“同类引擎经验”优先定位本次总结的产物。目标已删除时提示并保留当前页面。

任务切换、存储和模块职责见[架构说明](architecture.md)，引擎版本操作见[引擎库管理](adapters/README.md#引擎库管理)。
