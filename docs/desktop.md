# 桌面操作

## 从识别到试译

1. 在“添加游戏”选择具体游戏的安装目录，再打开该项目的“识别游戏”。已有项目的译文和校对可继续使用。[识别与智能适配](adapters/automatic-adaptation.md)
2. 在“翻译与校对”选几条容易在游戏里找到的对白或菜单，点击“试译并生成补丁”。
3. 生成后，在“翻译与校对”顶部点击“安装最近的试译补丁…”，核对补丁所含译文数量和游戏目录后确认安装。更改选区不会改变已生成的补丁。
4. 启动游戏，确认显示、换行、菜单和存档，再做全量翻译。“补丁与验证”提供启动入口，可选择“效果正常”记录运行结果，或选择“有问题，继续修复”。

需要自动试译验证或制作全量补丁时，在识别对话框的“本次目标”中选择“自动汉化”。[全自动汉化流程](automatic-workflow.md)

## 文本选区与校对

- “选本页”和“全选匹配”都加入同一选区。选区跨页保留。“仅显示已选”下取消最后一条或清空选区，会返回当前搜索和筛选结果。
- 普通翻译复用有效译文，重译只处理选区。失败条目可用“翻译失败”筛选，旧的有效译文仍可使用。[失败与继续](model-providers.md#批次失败与继续)
- 来源和校对状态分别显示。自动译文经确认后仍标为自动，修改文字并保存后标为人工。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+S | 保存译文 |
| Ctrl+Enter | 确认校对并前进 |
| Alt+↑ / Alt+↓ | 切换文本 |
| Ctrl+K | 搜索 |

## 游戏启动

在“项目设置 → 配置启动入口”选择游戏或启动器 EXE。需要转区或特定参数时，在这里配置原游戏的启动方式。工作目录留空时使用游戏目录，参数按 Windows 命令行传递。

安装补丁后会使用补丁声明的入口，或沿用原游戏配置。“恢复原版”后恢复原入口。启动前须完成中断的安装或恢复操作。[恢复原版](data-storage.md#保存与清理)

## 游戏运行检查

打开“补丁与验证 → 运行检查”，可检查启动、当前画面或预设场景。用“使用文本页选区”设置 OCR 目标。手动检查使用已保存的译文，自动试译可指定一条原文。检查启动前需退出已有游戏进程。

验证场景可选“启动后直接检查”或“启动后按 Enter”。自定义场景操作每行一条，可填 `等待 1000`、`按键 Enter` 或 `点击 50 50`。点击坐标按客户区百分比填写，执行时游戏须在前台且目标可见。

文字检查需要 Windows 10 1903 或更新版本及对应的系统 OCR 语言包。检查使用本地临时画面，结果只说明所检场景。遇到“无法确认”可检查语言包、识别区域或目标文本。

## 查找任务与补丁

项目任务在切换页面后继续运行。使用“任务详情”查看进度、错误和 Token，日志入口在项目底部。[解读消耗指标](consumption-metrics.md)

“打开补丁文件”打开可部署的 `files/`。“查看本次文本”显示生成该补丁时采用的译文快照。[补丁文件与报告](adapters/artifacts.md#汉化运行文件与补丁记录)
