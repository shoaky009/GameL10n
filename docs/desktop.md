# 桌面交互与状态

桌面界面使用 Slint，跟随系统深浅主题，时间按系统时区显示。

左侧区分游戏项目与全局功能；项目顶部显示可复制的目录及四个页面入口。全量翻译、选区和校对操作集中在“翻译与校对”，补丁生成、安装、启动和效果记录集中在“补丁与验证”。

## 窗口状态

正常退出时记住窗口位置、大小和最大化状态，下次启动自动恢复。最小化不影响已保存的普通窗口尺寸，也不会在启动时恢复为最小化。

窗口大小按界面逻辑尺寸保存，适应系统缩放变化；原显示器不可用时移回主显示器，超出屏幕的窗口会调整回可见区域。状态文件缺失或损坏时使用默认窗口设置。

## 项目列表与按需加载

添加项目时选择具体游戏的安装目录。目录疑似包含多个游戏时会提示确认；磁盘或共享根目录不能作为项目。

选择目录和添加项目期间，“添加游戏”按钮暂时禁用，重复触发不会打开多个选择窗口。取消或添加结束后可再次使用。

添加或重新添加游戏只登记项目，保留已有文本和校对数据，不启动识别或提取。点击“识别游戏”后，优先找回该游戏已有的适配器并执行本地探测、校验和提取；删除文本数据后也通过识别重新提取。已有实现通过本地检查时无需调用分析 API，其他游戏仍遵守运行验证门槛。

运行或排队的项目置顶，其余按最近更新时间排序，支持名称搜索。浏览项目和任务进度不改变排序时间。

打开项目只读取设置和已有结果，不自动识别。进入“翻译与校对”后才加载文本和保存的勾选，文本分页显示并复用缓存。尚未提取时显示等待提示，已有提取文件损坏时报告错误。

项目未单独配置的选项使用全局默认，修改后仅该项采用项目值，详见[模型接口配置](model-providers.md#按用途选择)。

## 游戏启动

在“项目设置”打开“配置启动入口”，选择游戏或启动器 EXE，填写可选启动参数和工作目录。“补丁与验证”的“启动设置”可跳转到该配置。工作目录留空时使用游戏目录；启动参数按 Windows 命令行原样传递，含空格的参数应按启动程序要求加引号。

识别完成后，优先采用适配器声明的入口，其次检查配套资源和唯一可用候选。多个 EXE 无法明确区分时显示原因和候选，由用户选择；也可点击“检测入口”更新候选。手动选择会保留，“使用自动配置”可撤销当前手动覆盖。

检测到转区配置且未声明明确启动路线时，需要手动选择所需启动器并填写参数。

通过程序安装补丁后使用其元数据声明的启动程序、参数和工作目录；纯资源补丁可以引用游戏已有 EXE，未声明则沿用原配置。恢复原版后切回原游戏配置。补丁入口的手动修改只对当前补丁生效。安装或恢复中断时，须先完成该操作再启动。

“启动游戏”仅启动所选程序，游戏内显示仍通过现有运行验证入口确认。

## 游戏运行检查

在“补丁与验证”打开“运行检查”，可分别检查启动、检查当前译文，或启动后执行保存的简单操作再检查译文。补丁通过现有入口自行安装，运行检查不改变补丁、适配器的验证资格，也不触发翻译或修复。

启动检查需要先关闭游戏。出现唯一的实际游戏窗口并稳定运行三秒后显示通过；启动失败、提前退出或识别到错误弹窗时显示未通过。无法跟踪启动器交接、窗口不明确或超时时显示无法确认。通过只表示观察期间的启动情况。

在文本页选中译文，再使用“文本页选区”保存检查目标。识别忽略空白、换行和全角拉丁字符差异，任意一条至少含四个文字或数字、区别于原文的译文稳定出现即通过。结果只表示当前画面；未检测到译文不直接认定补丁无效。手动进入对白后可直接检查当前画面，无需重启游戏。

识别使用 Windows 本地 OCR 和临时窗口画面，不调用模型，不保存截图、OCR 历史或检查报告。需要 Windows 10 1903 以上及所选语言的系统 OCR 语言包；不支持的捕获环境、识别不可用或文字不稳定时显示无法确认。可调整识别区域和语言后重试。

操作支持“等待 1000”“按键 Enter”“点击 50 50”，每行一个，点击坐标为客户区百分比。操作仅在“启动并检查”时执行，失焦或点击位置被遮挡时停止发送输入。检查可随时停止，正常游戏窗口保持打开。关闭运行检查或退出程序时，尝试关闭本次检查记录的错误窗口，清理前再次核对窗口、进程身份和错误类型。

## 文本选区与校对

- 未选择文本时，可“选本页”或“全选匹配”；有选择时统一显示“取消选择”，一次移除全部勾选。选区跨页和筛选保留，可切换为仅显示已选文本。
- 原文、译文和上下文支持文字选择与复制。“复制原文／译文”复制完整内容，校对区复制当前编辑内容。
- 切换文本、翻页、筛选或生成补丁前保存编辑。后台刷新保留未保存草稿，其他项目的结果不会覆盖当前编辑器。
- 普通翻译复用有效译文；重新翻译只处理所选文本。失败记录与旧有效译文独立，可通过“翻译失败”筛选重试。

来源与校对分别显示标签：蓝色自动、青色人工、绿色已校对、琥珀色待校对、红色格式问题。失败和候选可同时显示，颜色均配文字说明。直接确认自动译文或采用自动候选保留自动来源，实际修改文字后保存才记为人工；缺少可信来源的旧记录显示“来源未知”。“已保护译文”筛选表示普通翻译会保留的编辑或校对记录，不等同于人工来源。

右侧保留可编辑译文与保存、校对操作，原文和辅助详情单独滚动。上下文和模型初稿默认折叠，从“展开详情”查看；存在问题或候选时显示明确入口，新候选到达后自动展开。未保存修改有明确提示；Ctrl+S 保存、Ctrl+Enter 确认校对并前进、Alt+上下方向键切换文本，Ctrl+K 聚焦搜索。

## 任务、结果与日志

“识别游戏”先执行常规适配，必要时进入智能适配；状态分别显示当前路径。修复问题或补全遗漏文字直接进入对应智能任务，流程见[识别与智能适配](adapters/automatic-adaptation.md)。

运行中的任务在跨页反馈条中保留项目名称、状态和停止入口；翻译任务可暂停并保存进度。展开“任务详情”可查看当前步骤、API 和 Token 用量。已完成项目显示识别结果、支持范围和待验证项。Token 使用 K / M 简写，悬浮可查看精确值。

项目底部日志默认收起，展开后自动跟随，向上滚动后暂停，可点击“回到最新”恢复。小窗口展开任务详情或日志时，项目内容可纵向滚动，切换项目或页面回到顶部。错误会在反馈条中显示并提供完整原因，日志和错误详情支持选中复制。处理文件时显示操作、文件名和大小；模型进展与日志规则见[执行与恢复机制](adapters/adaptation-internals.md#进展结果与用户日志)。

## 消耗指标

左侧“消耗指标”支持按日期、版本、模型配置、游戏和任务类型组合筛选。模型配置按“配置名称 / 模型 ID / 推理强度”区分，Token 用量用三种颜色的折线展示输入、输出和缓存输入，其他指标使用柱条，并可切换到执行记录。统计口径及轻量存储见[消耗指标](consumption-metrics.md)。

## 补丁文件

“补丁与验证 → 打开补丁文件”打开补丁的 `files/`，其中的目录结构与游戏一致，可直接复制全部内容到游戏目录并覆盖。清单、报告和验证记录保留在该目录之外，详见[补丁产物](adapters/artifacts.md#汉化运行文件与补丁记录)。

## 导航与引擎库跳转

左侧底部的“关于”显示项目简介、软件版本号、构建时的 Git 提交哈希、GitHub 仓库地址和主程序许可证。版本、哈希和仓库地址支持选中复制；仓库、发布更新、问题反馈、使用文档、更新日志、许可证及第三方声明可在默认浏览器打开。版本、仓库和许可标识取自应用的 Cargo 元数据；没有可读取 Git 信息的构建显示哈希为“未知”。安装后的程序不需要 Git 即可查看这些信息，访问在线链接需要网络连接。

项目中的引擎和适配器版本、引擎库中的兼容游戏与经验来源均可通过名称链接跳转。“同类引擎经验”优先定位本次总结的产物。目标已删除时提示并保留当前页面。

任务切换、存储和模块职责见[架构说明](architecture.md)，引擎版本操作见[引擎库管理](adapters/README.md#引擎库管理)。
