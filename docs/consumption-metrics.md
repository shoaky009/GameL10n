# 消耗指标

左侧“消耗指标”用于查看全局 Token 消耗，覆盖文本翻译（含全量翻译、试译、重新翻译与候选译文）、术语提取、智能适配（含修复与扩展覆盖）以及经验总结。

页面支持按日期、游戏项目、模型配置和任务类型筛选，并自动忽略未调用模型的纯本地命中（例如常规本地识别或全部命中本地翻译记忆的运行）。

## 视图说明

- **顶部汇总**：展示当前筛选范围内的总消耗 Token、未缓存输入、缓存输入（及命中率）与输出 Token；鼠标悬停可查看精确计数与耗时明细。
- **消耗分布**：按游戏项目、模型配置或任务类型排行，默认按总 Token 降序排列，并用分段条直观展示未缓存输入、缓存输入与输出占比；按游戏查看或浏览执行记录时可直接跳转到对应项目。
- **每日趋势**：按日期展示用量走势，可切换“输入与缓存趋势”“总 Token 趋势”与独立纵轴的“输出 Token 趋势”。
- **执行记录**：按时间倒序列出每次调用的模型、请求次数、耗时与 Token 构成。

## 读懂数值

- **输入与缓存**：总输入已包含缓存输入。未缓存输入为总输入扣除缓存输入后的部分；缓存命中率仅在服务商返回了缓存计数的请求上按输入加权计算。
- **多 API 翻译链**：一次翻译任务若依次调用了链中的多个 API，会按实际发出请求的模型分别记账，不把回退模型的消耗算在主模型名下。
- **未知与部分计数**：“未知”表示服务商没有返回有效计数，“≥”表示仅汇总已知部分。失败和重试的请求也计入次数，返回的有效用量一并统计。
- **仅统计 Token 与耗时**：不内置模型单价或费用估算，实际金额以服务商账单为准。

指标随应用数据迁移，独立于项目日志。长时间运行每分钟自动保存进度；异常退出时可能丢失最近一小段计数，未正常结束的记录会标记为中断。[数据目录与迁移](data-storage.md)
