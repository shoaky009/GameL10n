# 消耗指标

左侧“消耗指标”用于比较识别、智能适配、修复、补全覆盖和经验总结的执行消耗。可按日期、版本、模型配置、游戏和任务类型筛选，切换“分组趋势”和“执行记录”。

比较模型或版本时，可限定相同游戏和任务类型，查看单次运行平均值。模型按配置名称、模型 ID 和推理强度区分，使用运行当时的配置。

## 读懂数值

- **输入与缓存**。输入已包含缓存输入。缓存命中率只统计有缓存计数的请求，以缓存输入合计除以这些请求的输入合计。
- **未知与部分计数**。“未知”表示服务商没有返回有效计数，“≥”表示仅汇总已知部分。失败和重试的请求也计入次数，返回的有效用量一并统计。
- **耗时与续接**。每次开始或继续独立计量，暂停间隔与复用结果的原执行消耗不重复累计。总耗时含本地操作、API 和等待时间。
- **金额**。费用以服务商实际计费为准，页面提供 Token 和耗时。

指标随应用数据迁移，独立于项目日志。异常退出时可能丢失最近一段计数，已保存且未结束的运行会标记为中断。[数据目录与迁移](data-storage.md)
