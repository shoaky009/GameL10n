# System4 AIN v14 MSG1 + FNL

该适配器处理 AI2 压缩的 AIN v14 剧情消息和 FNL 位图字库。使用资源特征和运行时代码识别游戏，不依赖游戏名。已验证资源样本为《母爛漫》；同引擎的其他代码版本需要单独确认兼容性。

剧情译文中缺少的字形使用 Windows 宋体补全，保留原有字形。最多支持 1880 个共享的额外 BMP 字符；缺字、码位耗尽或运行时代码不匹配时明确报错。STR0、EX、程序菜单和图片文字尚不在提取范围内，因此部分人名、选项和界面仍可能显示日文。

补丁包含配套的 AIN、FNL 和必要的 `.zh.exe`。安装后使用生成的中文启动程序，原 EXE 保留。仅替换字库不能解决部分 System4 运行程序不识别中文私用码位的问题。

修补规则按完整代码节 SHA256 和 PE 布局匹配；同一运行时仅图标、文件名或版本资源不同可以复用。代码不同的 EXE 不会直接套用旧修改位置，需要继续智能适配分析。

资源回填、中文字形和程序结构检查已通过；实际游戏启动、显示、排版和存档兼容性仍需通过试译确认。
