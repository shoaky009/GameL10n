# Unity SerializedFile 对话与已确认文本布局

标识：`engine.unity-textasset-dialogue-json`。适用于已验证的 Unity 2022 SerializedFile v22、对话 JSON、MonoBehaviour 文本字段与 TMP 字体回退组合。Unity 版本相同不能证明业务类的字段布局一致。

固定布局仅适用于已确认的业务类型和资源版本，不是通用 Unity 文本扫描器。其他游戏或版本需要单独核对字段语义、偏移和资源结构。

支持范围包括对话、已确认字段中的标题与说明、部分动态说明模板。内部 key、对象名、引用及其余二进制字段保留；运行时拼接的文字需要另行确认来源，不能仅凭字段名称判定可翻译。

验证包括独立原文样本、原字节往返、完整中文变长回填及局部试译；游戏实际显示仍需确认。动态模板中的 `(xx0x1)`、`(+x0%x1)`、`(+x0%)`、`(*)` 由主程序作为控制标记保留。

动态生成的说明、输入设置和运行时更新的界面不保证完整覆盖，具体遗漏保存在各项目的覆盖待办中。IL2CPP 字符串表和输入动作名包含程序查找键，不能整体当作翻译文本。TMP 回退字体可用也不代表字号、换行和布局已经验证。
