# Artemis PFS 覆盖卷

部分 Artemis 运行时支持主包与 `.pfs.NNN` 数字卷，每卷为完整 PFS，后加载卷覆盖同路径资源。加载规则确认后，可只输出修改脚本和必要字体，保留原媒体包。

固定 Python 工具库提供索引、成员读取、多卷合并与构建，卷名由候选路径确定并保存。适配器须实现 `overlay` 并通过源与补丁联合验收，保留文本 ID、路径和上下文。规则不明或格式不符时使用完整重建。

现有重建适配器需修改并重新验收后才能采用覆盖卷。脚本范围见[VNTextPatch](vntextpatch.md)，输出及安装协议见[验收机制](../adaptation-internals.md#验收与结果复用)。
