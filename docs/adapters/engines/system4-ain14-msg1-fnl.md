# System4 AIN v14 MSG1 + FNL

处理 AI2 压缩 AIN v14 的 MSG1 剧情消息与 FNL 位图字库，按资源结构和运行时代码匹配。

缺字使用 Windows 宋体补全，保留原字形，最多 1880 个共享额外 BMP 字符。STR0、EX 和程序菜单未提取，部分人名与选项可能遗漏；缺字、容量不足或代码不匹配时报错。

补丁输出 AIN、FNL 和必要的 `.zh.exe`，保留原 EXE。修补规则核对完整代码节 SHA256 与 PE 布局；代码相同而图标、文件名或版本资源不同可复用，其他版本需继续适配。

资源、字形与程序结构分别验收，运行效果通过试译确认。
