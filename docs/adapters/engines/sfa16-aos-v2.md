# LiLiM SFA16 / AOS v2 / SCR

> 完整产品的能力与协议参考；Rust 宿主的实际接入范围见[开发文档](../../development.md)。

适配器标识：`engine.sfa16.aos-v2`。

处理 AOS v2 容器中的 Huffman 压缩 SCR 脚本，提取对白、旁白、角色名和选择项，保留脚本命令、注释、资源路径和非脚本数据。脚本处理与特定可执行文件版本的补丁参数分开维护。

## 适用条件与验证

脚本资源必须符合当前支持的 AOS v2 / SCR 布局。中文运行补丁仅对已登记的 EXE 指纹生效，不能对其他运行时直接套用修改位置。

资源验收检查原文逐字节回填、中文测试文本回填与重新提取，以及非文本结构完整性。使用合成测试文本通过验收，不代表完整译文或实际运行表现已经确认。

## 汉化文件

- `sfa16.zh.exe`：新增的中文渲染程序，保留原 `sfa16.exe`。
- `scr.aos`：汉化后的剧情资源，替换前备份原文件。
- `patch-manifest.json`、`translation-report.json`：产物清单、文件指纹和验证结果。安装器只安装清单声明的游戏文件。

安装后通过 `sfa16.zh.exe` 启动。

## 限制

中文渲染使用 CP936 和 Windows SimSun 字体。回填时将 `♪` 显示为 `～`、`・` 显示为 `·`，适用于译文和保留原文的文本；原文快照和译文缓存保留原字符，产物报告记录受影响的文本数量。其他不能表示的字符会被拒绝，并提示具体字符及脚本位置。图片文字、视频、程序菜单和其他 AOS 版本不在该适配范围内。未登记的 EXE 指纹不会应用现有补丁参数。

实际中文显示、换行排版、剧情分支和存档兼容性尚未经过游戏运行验证。
