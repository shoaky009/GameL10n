# LiLiM SFA16 / AOS v2 / SCR

标识：`engine.sfa16.aos-v2`。处理 AOS v2 中 Huffman 压缩的 SCR，提取对白、旁白、角色名和选项，保留命令、资源路径与非文本数据。

## 适用条件与验证

资源须符合支持的 AOS v2 / SCR 布局，运行补丁须匹配已登记的 EXE 指纹。验收检查原字节往返、中文回填、复提及结构完整性。

## 汉化文件

- `sfa16.zh.exe`：中文启动程序，保留原 `sfa16.exe`。
- `scr.aos`：汉化剧情资源。

通过 `sfa16.zh.exe` 启动，补丁报告和安装规则见[产物约定](../artifacts.md#汉化运行文件与补丁记录)。

## 限制

使用 CP936 和 Windows SimSun。构建将 `♪` 显示为 `～`、`・` 显示为 `·`，报告影响数量，原文与译文缓存保留原字符。其他不可编码字符报错。

图片、视频、程序菜单及其他 AOS 版本不在范围内。实际显示、排版、分支和存档尚未经过游戏运行验证。
