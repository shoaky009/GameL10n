# Siglus / Scene.pck

标识：`engine.siglus`。识别后先选段试译，安装补丁并通过 `<原程序名>.zh.exe` 启动。需要转区时沿用原方式，原 EXE 的 `.le.config` 会复制给中文 EXE。

## 支持范围

- `Scene.pck` 与 132 字节头的场景脚本，密钥从当前 EXE 读取。
- 已确认显示调用中的对白和角色名，按字节码引用定位。
- FKDS 48/441 模板：每页 441 个 48×48 字形，按 Unicode 编号索引 G00 字库。
- UTF-16 变长回填，保留未改字符串、字节码、其他场景及内嵌源码。

图片内文字与未识别的自定义界面不在提取范围。其他布局进入智能适配。

## 补丁与字体

中文 EXE 只修补特征匹配的字体字符集筛选，保留原语言、区域与 PE 布局。剧情包和字体配置保持原路径。

普通字体使用 SimSun；FKDS 保留原字形，为缺字生成宋体位图并输出涉及页面。仅支持 BMP 字符，无法渲染时拒绝构建。

## 扩展与依赖

`tools/siglus-rules.json` 定义显示命令、从零开始的文本参数位置及类型，语义须由内嵌源码或字节码证据确认。

依赖固定 SiglusSceneScriptUtility 0.5.7、共享 Python 与 Windows x64 加速模块。工具版本由发行包或 `extensions/engine-tools` 提供，准备见[开发文档](../../development.md#工具准备)。
