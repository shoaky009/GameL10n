# Siglus / Scene.pck

标识：`engine.siglus`。内置版本：`1.0.0`。

导入游戏后点击“常规识别与提取”，再选择能在游戏中定位的少量文本试译。安装试译补丁后，通过生成的 `<原程序名>.zh.exe` 进入游戏。需要 Locale Emulator 的游戏仍应使用原来的转区方式；已有 EXE 对应的 `.le.config` 会复制给中文 EXE。

## 支持范围

- `Scene.pck` 场景包与 132 字节头的场景脚本。资源密钥从当前游戏 EXE 读取，不按游戏名匹配。
- 标准对白、角色名和经确认的显示调用。按字节码中的字符串引用定位，原文相同的不同记录可以分别翻译。
- FKDS 48/441 气泡模板：每页 441 个 48×48 字形，以 Unicode 字符编号索引 G00 图片字库。需要内嵌源码和字库布局符合模板；未识别的版本转入智能适配。
- UTF-16 变长回填，保留字节码、未修改字符串、其他场景与内嵌源码。原文回填保持字节一致。

CG、背景图中的文字及未识别的自定义界面不包含在提取范围内。图片字库补字仅处理渲染剧情文本需要的字符。

## 补丁与字体

保留原 EXE，另生成中文 EXE，只修改经过特征检查的字体字符集筛选字节，保留原语言、区域设置和 PE 布局。剧情包和字体配置使用原资源路径，安装时由统一安装器备份必须替换的文件。

普通字体设置使用 Windows 自带的 SimSun（宋体）。FKDS 保留已有字形，仅为缺字生成宋体位图，输出涉及的字库页；字体风格可能与原字形略有差异。只支持 BMP 字符，不接受无法渲染的字符或静默问号替换。

结构校验包含字符串回读、非文本数据完整性、中文字形和 EXE 检查。它不等同于实际启动、显示、换行或存档兼容验证。

## 扩展与依赖

新增显示规则由固定版本的 Siglus 解析器和 `tools/siglus-rules.json` 配置共同处理。配置记录显示命令、从 0 开始的文字参数位置和文本类型；参数含义需要从内嵌源码或已验证的字节码语义确认。新增提取规则不等于支持新的字体或显示系统，修改后仍需完整验收。

共享工具为固定版本 SiglusSceneScriptUtility 0.5.7、Python 3.14.10 和 Windows x64 加速模块，保存在应用数据目录的 `extensions/engine-tools`。Python 直接读取发行包的 `tools/engine-tools` 或已有共享运行时，不自动下载；解析工具已随应用附带，不需要系统 Python、pip 或付费 API。游戏目录中不放工具、源码、缓存或开发记录。
