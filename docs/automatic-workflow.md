# 全自动汉化流程

在“识别与适配”的“本次目标”中选择“自动汉化”，再选择完成目标。开始前请关闭游戏。

| 完成目标 | 结果 |
| --- | --- |
| 仅试译并验证 | 安装试译补丁，确认译文显示后结束。 |
| 验证后生成全量补丁 | 验证通过后全量翻译并生成补丁，可稍后手动安装。 |
| 验证后生成并安装全量补丁 | 验证通过后全量翻译，并生成和安装全量补丁。 |

在“项目设置 → 配置自动汉化”保存项目默认选项。已有提取结果时可勾选“使用已有提取文本”。识别对话框中的调整只用于本次运行。

## 选择验证场景

在“运行检查”设置启动后直接检查、按 Enter 或自定义场景操作。可以从文本页指定一条原文作为试译目标。未指定唯一目标时，流程用 Windows OCR 从原版画面匹配一条对白或旁白。无法定位时，调整场景或指定文本后重新运行。[游戏运行检查](desktop.md#游戏运行检查)

自动从画面定位目标前会尝试恢复本程序安装的补丁，以读取原文。恢复冲突时停止。开始检查前需关闭原先运行的游戏。

## 失败、取消与恢复

失败或中断时，已保存的译文和补丁仍可使用。重新运行从配置入口开始，会复用有效结果。已安装的试译补丁可能仍在游戏目录，可用“恢复原版”。阶段和原因见任务详情及日志。[恢复规则](data-storage.md#保存与清理)

OCR 通过只表示目标译文在当前画面可读。全量安装后仍需确认实际显示、分支和存档。启动补丁时会在宿主环境运行其中的可执行代码。[补丁运行的风险](adapters/execution-isolation.md#补丁运行的风险)

## 自定义流程

项目已有自定义 `workflow.json` 时，可以选择“使用自定义流程”。切换预设会保留该文件。全量处理仍要求本次试译验证通过。[流程定义与校验](../crates/core/src/workflow.rs)

命令行 `gamel10n workflow <项目ID>` 使用项目保存的流程选择，支持 `--intelligent` 和 `--instruction`。
