# 全自动汉化流程

在“识别与适配”的“本次目标”中选择“自动汉化”，再选择完成目标。开始前请关闭游戏。

| 完成目标 | 结果 |
| --- | --- |
| 仅试译并验证 | 安装试译补丁，等待实机把关确认后结束。 |
| 验证后生成全量补丁 | 实机确认通过后全量翻译并生成补丁，可稍后手动安装。 |
| 验证后生成并安装全量补丁 | 实机确认通过后全量翻译，并生成和安装全量补丁。 |

在“项目设置 → 配置自动汉化”保存项目默认选项。已有提取结果时可勾选“使用已有提取文本”。识别对话框中的调整只用于本次运行。

## 试译选区与实机把关

1. **确定试译文本**：如果运行前已在“翻译与校对”勾选了试译文本，流程会直接使用当前选区；若尚未勾选，流程会在识别完成后暂停，并在项目顶部显示提示卡片，引导前往文本页勾选后点击“继续试译”。
2. **人工实机把关**：试译补丁生成并安装后，流程会暂停并在顶部显示把关卡片，提供“启动游戏”“查看试译文本”“确认正常，继续后续流程”和“有问题，去修复”。
3. **继续或修复**：进入游戏确认中文显示、字体和换行无误并关闭游戏后，点击确认按钮即可记录当前补丁效果正常，并自动执行后续的全量翻译、补丁生成与安装；若显示异常，可直接进入修复模式调整适配器。

## 失败、取消与恢复

失败、暂停或程序重启时，当前等待进度、已保存的译文和补丁均会保留。重新打开项目后可直接在顶部把关卡片继续，也可以点击关闭按钮结束本次流程。已安装的试译补丁可能仍在游戏目录，可用“恢复原版”。阶段和原因见任务详情及日志。[恢复规则](data-storage.md#保存与清理)

启动补丁时会在宿主环境运行其中的可执行代码，全量安装后仍需确认实际显示、分支和存档。[补丁运行的风险](adapters/execution-isolation.md#补丁运行的风险)

## 自定义流程

项目已有自定义 `workflow.json` 时，可以选择“使用自定义流程”。切换预设会保留该文件。全量处理仍要求本次试译经过实机确认。[流程定义与校验](../crates/core/src/workflow.rs)

命令行 `gamel10n workflow <项目ID>` 使用项目保存的流程选择，支持 `--intelligent` 和 `--instruction`。
