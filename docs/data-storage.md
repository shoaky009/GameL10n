# 数据目录与迁移

默认数据目录是 `%LOCALAPPDATA%\GameL10n`。在“程序设置 → 打开数据目录”可查看当前实际位置。

## 保存位置

在“程序设置 → 更换保存位置”选择操作。

| 操作 | 结果 |
| --- | --- |
| 迁移并切换 | 复制并校验数据，再加载目标目录。目标须为空或包含相同副本，原目录保留。 |
| 仅切换 | 直接打开目标的数据。空目录显示为空游戏库。 |

切换前暂停任务并保存状态。两个目录须彼此独立，且与游戏安装目录分开。迁移失败时仍使用原目录，可选择同一目标继续。

启动时，`GAMEL10N_DATA` 优先于兼容变量 `AVG_TRANSLATOR_DATA` 和界面保存的位置。使用环境变量时，界面切换仅对本次运行生效。程序也支持读取旧版 `%LOCALAPPDATA%\AvgTranslator` 的数据。窗口位置独立于游戏数据目录保存。

## 备份与恢复

备份或迁移时，保留整个应用数据目录及游戏安装目录的原版备份。项目身份绑定游戏安装路径，更改路径会当作另一个项目。迁移到其他 Windows 用户或电脑时需重新输入 API Key。

| 位置 | 用途 |
| --- | --- |
| `settings.json` | 全局设置、接口配置和本机加密密钥 |
| `games/<项目 ID>/` | 项目设置、已提取文本、译文、校对、补丁及日志 |
| `extensions/` | 共享适配器、兼容记录、依赖和引擎经验 |
| `metrics/` | 各次运行的消耗记录 |

需要单独备份译文时，一并保留 `translation-edits.json` 和 `translation-edits.jsonl`。翻译记忆和项目资料也可能包含可复用译文，完整备份以整个目录为单位。

重启后，未结束的任务标记为中断。已提交的译文和补丁可继续使用。项目文件缺失但列表记录仍在时，可以打开或移除项目，或重新识别以补回提取结果。

## 工作台文本与版本升级

每个游戏项目在首次浏览已提取文本时自动准备分页文件。原有提取结果、翻译记忆、校对和选区继续使用，升级无需调用翻译接口。升级成功后，版本记录保存在项目目录的 `project-migrations.json`。后续打开直接使用现有分页文件，应用启动时无需逐个升级游戏库中的项目。

`workbench-v1/pages.bin` 按提取顺序每 100 条存一块，`pages.idx` 保存页位置、文本 ID 定位和统计。索引缺失或校验失败时，工作台会自动从分页文件重建索引。分页文件也损坏时，工作台会从项目的提取结果和翻译记忆重新生成，再应用已保存的校对。恢复依赖这些原始项目文件，备份时请保留整个项目目录。

## 保存与清理

### 安装和恢复原版

通过程序首次替换游戏文件时，会在游戏目录保存原件 `.bak`，在项目的 `installation.json` 记录安装状态。恢复原版依赖这两处。恢复会核对备份，放回原文件并移除该补丁新增的文件；遇到冲突时保留文件并报错。安装或恢复中断后，可从同一入口继续。

后续提取和补丁制作读取原件或安装记录中的原版备份。旧项目的 `sources/` 是制作输入。手动覆盖文件前请自行备份。

### 项目完工后清理

在“项目设置 → 清理项目文件…”查看大小并选择类别。操作不可撤销。

| 可选类别 | 清理影响 |
| --- | --- |
| 适配开发资料 | 无法续接原会话或用已删除的资料总结经验。 |
| 原文工作资源 | 清理旧版原文副本后，重新制作补丁前可能需要重新识别。 |
| 历史补丁 | 保留当前可识别的补丁及其译文快照和运行反馈。 |
| 过程日志与异常记录 | 删除诊断和请求异常记录。 |

已提取文本、译文、校对、当前补丁和安装记录可继续使用。清理限于当前项目资料，游戏目录内的文件和备份及全局适配器保留。[适配与补丁产物](adapters/artifacts.md)
