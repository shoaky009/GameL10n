# Engine archive reference fixture

`engine-archives-e9b8018.zip` contains only `python/__init__.py`, `python/archives/__init__.py`, `rpa.py` and `xp3.py` from [GalTransl-GalGameReverse-Skill](https://github.com/GalTransl/GalTransl-GalGameReverse-Skill/tree/e9b801879f37cee98a9dfc8afbbcf5ffa929c04c/python/archives), commit `e9b801879f37cee98a9dfc8afbbcf5ffa929c04c`. The archive modules retain their MIT copyright and license headers. It is an offline test fixture, not a production dependency or a substitute for the application's pinned library.

Archive component integration tests require Python 3.10+ for the test process. Set `GAMEL10N_TEST_PYTHON` to its executable, or provide `python3`/`python` on PATH; tests also recognize the application's bundled Python. Production components continue to require the shared, receipt-checked portable interpreter and never select system Python.

`kirikiri-scn-reference-442ae2f.zip` contains the package markers and `kirikiri_psb.py` / `kirikiri_scn.py` from GalTransl-GalGameReverse-Skill commit `442ae2ff5a8a2bdad43e9e99a10b4c224593221a`, together with its GPL-3.0 and GARbro MIT license texts. SCN component tests use synthetic PSB data generated by `check_kirikiri_scn_component.py`; no game resources are included. The tests check local reference edits, derived speech/search strings and lengths, unchanged data and explicit language selection using the real pinned reader/writer.
